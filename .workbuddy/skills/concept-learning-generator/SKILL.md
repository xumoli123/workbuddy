# 概念学习资料生成器（Concept Learning Generator）

## 用途

给定任意一个 AI 技术概念名称，生成一份**结构化、可复用、便于复习**的学习资料。本 Skill 是通用的，不绑定任何特定概念。

## 输入

- `concept`（必填）：概念名称，如 "RAG"、"Transformer"、"KV Cache"、"Mixture of Experts"。
- `depth`（可选）：期望深度，`入门`（默认）/ `进阶` / `专家`。
- `audience`（可选）：目标读者，默认为"有一定编程基础但不熟悉该概念的学习者"。

## 输出结构（六个固定模块，缺一不可）

针对输入的概念，依次生成以下六个模块（组织内容时可先用 Markdown 二级标题 `##` 打草稿，**最终交付物为完整的 HTML 学习文档**，见文末"输出格式要求"）：

### 1. 个人通俗解释
- 用一两句**生活化类比**把概念讲明白（例如："Embedding 就像给每个词发一张身份证，身份证上的数字编码了它的'性格'"）。
- 类比之后用一段话给出严格一点的一句话定义。
- 避免堆砌术语；如果必须用术语，先解释术语。

### 2. 核心机制
- 分点（3~5 条）说明这个概念**是怎么工作的**：输入是什么、内部发生了什么、输出是什么。
- 涉及关键公式或数据结构时，用文字+简单示意描述，不必展开完整推导。
- 注明该机制解决了什么前置问题（"没有它的话会怎样"）。

### 3. 真实应用场景
- 列出 2~4 个**真实存在**的产品或工程实践中的使用案例（如某公司的某功能）。
- 每个场景用"场景 → 为什么用到这个概念 → 效果"的格式写一两句话。

### 4. 易混淆边界
- 明确列出 2~3 组**最容易被混淆的相邻概念**（如 RAG vs 微调、Tokenizer vs Embedding）。
- 每组用"区别点 / 各自适用情况 / 一句话记忆口诀"三要素说清。

### 5. 权威参考链接
- 提供 3~5 条可核查的权威来源：原始论文（arXiv 链接）、官方文档、知名课程或教科书章节。
- 每条附一句话说明"这条链接讲了什么、适合什么时候看"。
- 只给真实存在的链接，不确定的来源宁可不给。

### 6. 自测思考题
- 出 3~5 道检验理解的问题，覆盖：概念本质（为什么需要它）、机制细节（它怎么工作）、边界辨析（它和邻居概念的区别）。
- 附上简短的参考答案要点（可折叠或放在题目下方）。

## 质量要求

- 全文使用简体中文，术语首次出现时标注英文原文。
- 内容必须**准确且可核查**：对拿不准的细节，先用搜索工具核实，不要编造论文、链接或数据。
- 篇幅控制在 800~1500 字，宁精勿滥。
- 保持六个模块的标题与顺序一致，方便跨概念横向对比。

## 输出格式要求（保留，不可省略）

- 最终输出**完整的 HTML 学习文档结构**：包含 `<!DOCTYPE html>`、`<html lang="zh-CN">`、`<head>`（charset、viewport、title、内嵌 CSS 样式）与 `<body>` 的完整文档，六个模块对应正文中的六个小节，可直接在浏览器中打开阅读。
- 文档保存至 `learning-materials/` 目录，文件名使用概念英文名（小写、连字符分隔），如 `lora.html`。
- 若概念之间有关联，可在文末附"延伸阅读"链接到库内已有的其他学习资料。

## 使用示例

用户："帮我生成关于 LoRA 的学习资料"
→ 按 `depth=入门` 输出六模块文档。

用户："用专家深度讲讲 Flash Attention"
→ 按 `depth=专家` 输出，核心机制模块可包含更多公式与显存/计算量分析。
